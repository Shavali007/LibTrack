# Backend

The Spring Boot API uses MySQL with Spring Data JPA and Flyway. By default it connects to `jdbc:mysql://localhost:3306/libtrack`, matching a locally installed MySQL server. Set `DB_URL` explicitly when using another endpoint. The optional Compose service targets MySQL 8.4 and maps to host port 3307 by default; copy `.env.example` to `.env`, replace both local password placeholders, start `docker compose up -d db`, and set `DB_URL=jdbc:mysql://localhost:3307/libtrack?serverTimezone=UTC` for that service. Set `DB_USERNAME` to `MYSQL_USER` and `DB_PASSWORD` to `MYSQL_PASSWORD`. Then run `mvn spring-boot:run` from this directory. Do not commit `.env` or use these local credentials outside development.

Flyway selects `classpath:db/migration/mysql` by default. Existing PostgreSQL migration files remain unchanged in `db/migration`; switching a populated PostgreSQL database to MySQL requires an explicit data export/import and is not performed automatically. H2 test runs disable Flyway and do not verify the MySQL schema.
